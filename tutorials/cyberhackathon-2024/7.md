# Exercise 7: With great power...

This is a challenge exercise.

Your goal is to find the password for file `7.c.`, such that, when compiled
and executed, the program outputs "You win!".

You cannot modify the behavior of the source code. You can add comments,
annotations, and modify the file itself, but you must not change its semantics
in any way.

You may use any tool you want; fuzzers and static analyzers can be very helpful.

If you decide to use some specific source code analyzer, such as, for instance,
Frama-C, some *special* options (hint, hint!) may be necessary.
But even with many options, Frama-C/Eva may only get you up to 90% of the
result. Some hints (in the form of comments) in the source file may help you
find the final piece. Some googling might be needed.

Good luck. Hope to C you succeed.
