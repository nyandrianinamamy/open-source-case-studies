# Exercise 0: Install and run Frama-C and Ivette

## Task 1: Install GCC/Clang

These exercices assume either GCC or Clang are available.

On macOS, this usually means Xcode must be installed.

From now on, we will use `gcc` in all examples, but you can replace it with
`clang` if you prefer.

Run `gcc 0.c` and check that you get the message "Congratulations!".

## Task 2: Install Frama-C

You must be able to install and run Frama-C 26.1.

Hint: use `opam`, the OCaml Package Manager.

Hint 2: avoid using your distribution's package manager, they often contain
older versions of `opam`, or install several OCaml dependencies. Binary
opam releases exist for many systems and are very easy to install: a single
binary that can be put directly in `/usr/local/bin` or in any directory in
your PATH.

If successful, running `frama-c -version` should output:

    26.1 (Iron)

## Task 3: Install and run Ivette

If you successfully installed Frama-C, you should have a prompt in the end
to tell you how to install Ivette.

Hint: you may need `nvm` and `yarn`.

Running `ivette` should open an Electron window.
