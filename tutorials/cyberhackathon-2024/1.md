# Exercise 1: Using C preprocessor flags

C applications often need preprocessor flags -I/-U to be compiled.

In this exercice, you need to succesfully parse `1.c` using Frama-C.

## Task 1: Parsing with GCC

Try parsing `1.c` with GCC, without any errors.

NOTE: you should not modify the code.

Hint: define necessary preprocessor symbols.

## Task 2: Parsing with Frama-C

Now do the same, but with Frama-C.

Hint: run `frama-c -kernel-help` and look for `-cpp-extra-args`.

Hint 2: If your option starts with `-`, you need to use `=` for Frama-C to
recognize it, e.g. `-cpp-extra-args="-A B"`.

If successful, you should obtain:

    [kernel] Parsing 1.c (with preprocessing)
