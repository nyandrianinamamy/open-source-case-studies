In `3.c`, we had a series of hard-coded and non-exhaustive test cases.
In this exercise, we will use Frama-C *built-in functions* to perform the
equivalent of billions of tests in a few lines of code.

in Frama-C's *share path* (given by `frama-c-config -print-share-path`).
This directory is automatically included by Frama-C, so you can simply use
`#include "__fc_builtin.h"` in the code.

### Task 3: Adding more guarantees

More than being UB-free, a function should compute what we expect it to.
Besides using the Eva Values panel to inspect results, we can add some ACSL
checks and assertions to bring us some guarantees.

Using your favorite editor, add an ACSL `check` annotation after the call to
`myabs`, to verify whether the function only returns non-negative values.

Note: Ivette only reports syntactic errors in the Console panel. It is often
better to run the command-line `frama-c` when learning ACSL syntax, so that the
error messages are easier to read. Switch to `ivette` once parsing succeeds.

Hint: an ACSL annotation must start with `/*@` or `//@`, without spaces between
the start of the comment and the `@`. It must end with a `;`.

## Task 5: Properly limiting input values

There are two possible approaches to make `myabs` correct:
1. Explicitly define an arbitrary result for values which cannot be correctly
   computed.
2. Treat it as a partial function and limit its input range;

The latter can be easily expressed in ACSL with a *function contract*.
Copy the following template just before the definition of `myabs`, completing it
as needed:

```
/*@
  requires <predicate about x>;
  ensures <predicate about \result>;
*/
```

Replace `<predicate about x>` with a logical condition that the input value `x`
must respect in order for `myabs` to return the expected value.

Replace `<predicate about \result>` with the same guarantees that you provided
in Task 3. Note that `\result` is the name of a "special variable" that
will contain the function result.

Then run Ivette + Eva and ensure that the contract is proved without alarms.

Note: Eva cannot prove the actual mathematical relation between input and
output, that is, `ensures \result == \abs(x);` (`\abs` is an ACSL logical
function on real numbers). Such functional proofs are usually performed using
plug-ins such as WP.
