# Frama-C/Binsec Cyberhackathon (2024)

This is a copy of the Frama-C files from the 2024 Cyberhackathon which took
place at Nano-Innov, CEA List.

Most of the instructions were given orally, so this repository is not entirely
self-contained. However, the exercices themselves have corresponding Markdown
files with the instructions.

Note that only a few of the solutions are available, in the `solutions`
directory.
